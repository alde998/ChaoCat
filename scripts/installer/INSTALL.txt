Chaos Cat 安装说明

本安装包适用于 macOS 13 及更新版本，文件名中的 arm64 表示 Apple Silicon Mac。

打开 DMG，将 ChaosCat.app 拖到 Applications 文件夹，然后从“应用程序”打开。安装包已包含小猫动画、本地联动服务需要的 Node.js 和 VS Code 扩展。

若已安装正式版 VS Code，小猫首次启动会自动为当前用户安装内置扩展；若 VS Code 已打开，请重新启动扩展宿主。若之后才安装 VS Code，可从小猫菜单选择“安装 VS Code 插件”。镜像中的 ChaosCat-VSCode.vsix 也可以在 VS Code 的“扩展”视图中通过“从 VSIX 安装”手动安装。

此版本没有 Apple Developer ID 签名和 Apple 公证，首次打开时 macOS 会拦截。若提示“Apple 无法检查 App 是不是包含恶意软件”或“无法验证开发者”，且确认文件来自官方 GitHub 发布页：

1. 先尝试从“应用程序”打开 ChaosCat，关闭警告对话框。
2. 打开“系统设置”>“隐私与安全性”，向下找到 ChaosCat 的拦截提示，点“仍要打开”。
3. 再次出现确认框后点“打开”。以后通常可以直接双击启动。

这是 Apple 官方提供的单个 App 例外操作，不需要关闭系统安全保护。若提示“App 会损坏你的电脑”或“App 已损坏”，请停止安装并向开发者反馈完整提示，不要尝试绕过。

Apple 官方说明：https://support.apple.com/zh-cn/102445
