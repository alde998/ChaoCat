# Chaos Cat

连接原生桌宠，输入时追虫，跳垃圾堆时插入临时占位，拉屎时在代码编辑区插入真实的 `/shit/` 字符串。

`/shit/` 是文档正文，保持可见、可选择、可搜索、可复制，并支持独立撤销；保存文档时会一并写入文件。放大的 💩 图标显示在文字旁边。直接单击 `/shit/` 删除单个标记，无需修饰键，不显示悬浮删除按钮。埋屎动作到达对应位置后，从文档正文删除该标记；周围文字保留。

打开代码文件并聚焦编辑器，状态栏显示“小猫 · 已联动”后，可通过命令面板的“Chaos Cat: 拉屎”触发三轮动作。

“Chaos Cat: 立即清理所有屎”和桌宠菜单“清理”立即删除当前文档及所有已记录受影响文档中的 `/shit/`，包括已关闭的标签页；不自动保存文档。清理会取消尚未完成的排便，避免延迟请求重新插入。无关文件不会被扫描。

“Chaos Cat: 调试埋屎动画”或快速拖拽小猫则按动画逐个埋屎。调试动作立即切换，可用于检验任意当前状态下的动画。

点击状态栏查看本机桥接、桌宠和当前编辑器的联动诊断。要求 VS Code 1.79.0 或更高版本，原生桌宠使用本机端口 44777。
