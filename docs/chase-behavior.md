# 追虫行为

- 编辑区：仅 `editor.textChanged` 输入事件判定触发，每 3 秒最多一次，概率 12%。编辑区闲置不触发。
- 非编辑区：在当前前台应用窗口内，每 8 秒判定一次，概率 3%。
- 追虫结束（超时、点击驱逐、拖拽或切换应用）后共用 25 秒冷却。
- 休息结束后才执行排队动作；输入已停超过 3 秒或前台窗口已变化时取消该次打字触发。
- 小虫按航点自主移动，普通飞行 52 点/秒、逃窜 78 点/秒；输入方向引导航点及朝向。猫跟随移动中的虫，而非旧输入坐标。
- 接近时复用 `rubbish-run-left/right` 原 GIF，通过 `chase-run-left/right` 显示配置使用已校准的 0.180842 比例；与垃圾堆奔跑同尺寸，按相同比例调整步距。远距离出现虫子时直接开始接近；远距离接近不使用小步快走过渡。
- 距扑击落脚点约 45 点时切入扑击；每随机 1–3 次扑击接翻滚及恢复动作。恢复动作仍在迈步后产生位移。
- 小虫可点击驱逐，16 秒后自动消失；切换前台窗口会退出本次追虫。

验证：`tests/BehaviorBugTriggerTests.swift` 覆盖概率、节流、编辑区闲置排除、冷却、自主飞行；`tests/BehaviorChaseTests.swift` 覆盖奔跑跟随、朝向、扑击/翻滚、边界位移和拖拽打断。

- 打字触发的出生点与最新输入坐标 x 对齐，锚点上移 28 点；加上虫身相对锚点的高度，显示在输入位置约 45–50 点上方。窗口边缘按虫子尺寸留白。
- 两次扑击之间必定插入一次 `chase` 小步追赶（1.2 倍速、约 0.69 秒，最多移动 60 点），包括翻滚恢复之后；短追赶后仍太远才使用奔跑段。
