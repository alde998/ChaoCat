| 休息 | 蹲坐 60%、舔爪 28%、睡觉 12%；坐下、保持或舔爪、起身；睡眠呼吸完整循环 3–5 次再起身 |

## 编辑器协议

macOS 的 `BehaviorController` 是唯一动作时钟；VS Code、Obsidian、Notion Web 适配器负责文本、坐标及删除回执。命令带目标来源和 requestId，修改串行执行。点击/拖拽取消旧动作后，过期回调不能继续启动动画。

垃圾堆插入 `        /rubbish/        `，不覆盖原代码。标记记录 UTF-16 偏移，随文本改动更新；退出只删除验证仍相同的标记。用户改动标记内部时，放弃该标记的自动删除权。扩展记录恢复上下文，程序异常退出后通过心跳超时恢复垃圾占位。

`/shit/` 是真实文档正文，保持可见且可选择、搜索、复制和保存；图标放在文字旁边，不遮盖正文。每次插入使用独立撤销边界，埋屎按记录删除对应字符串。0.1.2 的真实 VS Code 1.79.2 宿主测试验证了三次插入、撤销/重做、保存到磁盘、跨标签页立即清理和埋屎后保存恢复原文。

VS Code 优先使用 macOS Accessibility 的字符范围坐标；编辑器不提供字符范围时退回可见行、字体和编辑区域计算。Obsidian 使用编辑器坐标，Notion Web 使用 DOM Range。极端缩放、软换行或编辑器缺少坐标接口时，位置仍需结合实际窗口检查；不会因此扩大文字删除范围。

Obsidian / Notion Web 的代码适配器已更新；没有在本次会话中安装到实际 Obsidian 库或 Chrome 扩展配置，也没有声称完成这两个宿主的实际界面测试。
