# 用户规则与实现验收

- 默认走路，按每个步态周期的步距累加屏幕坐标，全局游走；方向改变随机用向内/向外转身。左右均支持。
- 休息概率：蹲坐 60%、舔爪 28%、睡觉 12%。坐下单次→蹲坐末帧保持或舔爪循环→起身单次；躺下单次；睡眠入睡→呼吸 3–5 次→苏醒，不在呼吸中强切。
- 追虫仅输入或手动触发：猫/虫分别抠图，远处追逐、近处追捕；虫平飞/逃窜同步。输入方向驱动虫，点击或超时驱逐并退出。
- 垃圾堆：静态图 + 猫发现/冲刺/跳入/摇尾巴独立段。代码插入 /rubbish/ 空间，保留原内容，拖拽或点击释放时只删除自己插入的占位，保留用户期间编辑。距离 ≤320pt 且面对垃圾堆才进入；冲刺周期重复直到抵达。摇尾巴持续到拖拽/点击。
- 拉屎共3轮，每轮真实 /shit/ 与动画事件同步，中间走路2–4秒，可转向。被打断→受惊狂奔，左右转向随机内/外素材。
- 埋屎按真实标记坐标寻路，粪便消失帧触发删除对应 /shit/；起身后走向下一处。编辑器滚动/改动后重新取位置，不删除无关文字。
- 菜单调试动作手动立即切换，不受休息或排便状态阻塞；选择菜单导致编辑器失焦时，仍使用原文档完成三轮排便。“清理”取消排便并立即清除桌面屎图层和已连接编辑器中所有受影响文档的屎标记，取消延迟插入；快速拖拽仍保留逐个埋屎。
- 拖拽预留提起、悬空、放下三段，暂用原 carried 素材；轻拖只移动，快速拖拽（至少24点，峰值≥900点/秒）松手放下后进入埋屎。打断拉屎则先狂奔再埋屎。拖拽期间保留原文档，重新抓起会取消旧回调。
- 保留原像素与源帧率；循环剪辑闭合；完整源视频不改；GIF有256色和二值透明限制。
- 验证：动画清单/帧数/透明度，猫虫分离、静态垃圾图；步距/距离门槛/取消与状态机测试；编辑范围恢复/异步顺序/三次排便/删除时机测试；release build及App资源验证。
